Đếm, kiểm tra, rồi ghép

k = int(input())
s = input().strip()
dem = {}
for c in s:
    dem[c] = dem.get(c, 0) + 1
T = ""
for c in sorted(dem):
    if dem[c] % k != 0:
        print(-1)
        exit()
    T += c * (dem[c] // k)
print(T * k)

dem: từ điển đếm số lần mỗi chữ

% lấy số dư. Dư khác 0 → in -1 và dừng

c * 2 = "cc", T * k lặp T đúng k lần

Python cho phép nhân chuỗi với số: "ab" * 3 = "ababab". Đây là mẹo giúp code bài này rất ngắn. Nếu học sinh chưa học từ điển, có thể dùng s.count(c) cho từng chữ từ a đến z.
