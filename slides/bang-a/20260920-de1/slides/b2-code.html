Sắp xếp rồi so hai số đứng cạnh nhau

n = int(input())
a = list(map(int, input().split()))
a.sort()
ans = 1
for i in range(1, n):
    if a[i] - a[i - 1] == 1:
        ans = 2
print(ans)

Sau khi sắp xếp: 1 2 10 20. Hai số liên tiếp sẽ đứng cạnh nhau.

Hiệu bằng 1 → cần 2 hộp.

Không cặp nào → giữ 1 hộp.

Câu hỏi thêm: không sắp xếp thì làm sao? Có thể dùng hai vòng lặp so mọi cặp; với N ≤ 1000 vẫn đủ nhanh, nhưng sắp xếp gọn hơn.
