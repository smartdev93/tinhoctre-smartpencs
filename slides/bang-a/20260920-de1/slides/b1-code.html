Hộp lớn trước, rồi thử hộp nhỏ

n = int(input())
lon = n // 210
du = n - lon * 210
ans = 0
for nho in range(du // 38 + 1):
    con = du - nho * 38
    banh = lon * 30 + nho * 5 + con // 9
    ans = max(ans, banh)
print(ans)

lon: số hộp lớn mua được

du: tiền còn lại, luôn dưới 210

nho: thử từng số hộp nhỏ, còn lại mua lẻ

// là phép chia lấy phần nguyên

Vòng for chạy tối đa 6 lần, dù N bằng 1 tỉ. Cho học sinh chạy thử với 210, 257 và 8 (kết quả 30, 36, 0).
